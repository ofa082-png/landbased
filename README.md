# Land-based salmon monitor

Quarterly production data for the six Oslo-listed land-based salmon producers — Salmon Evolution,
Nordic Aqua Partners, Proximar Seafood, Atlantic Sapphire, Gigante Salmon and Andfjord Salmon —
built from their own filings.

**Live page:** https://ofa082-png.github.io/landbased/

Every figure comes from company quarterly and annual reports and Oslo Børs NewsWeb announcements.
Growth, turnover, utilisation and capital per kg are calculated the same way for every company:

- growth = biomass out − biomass in + harvest converted to live weight (HOG × 1.205)
- daily growth = growth ÷ average standing biomass ÷ days; turnover annualises it
- the Norwegian sea benchmark on those two metrics is Fiskeridirektoratet's biomass statistics,
  calculated identically
- capital per kg is shown four ways, because the usual figures divide by capacity that is not producing

Cost per kg is each company's own definition and is not comparable between them; the page says so per company.
